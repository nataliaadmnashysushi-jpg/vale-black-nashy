Como usar
  • Mostre este vale no caixa. A equipe lê o QR code ou digita o código.
  • Peça a sua cortesia, qualquer drink ou sobremesa do cardápio, na mesma conta em que usar o vale.
  • Este vale funciona como dinheiro: quem apresentar o código ou o QR code pode usar. Não compartilhe com quem não vai usar. Pode dar de presente.
  • Não vale junto com o desconto de aniversário nem com outras promoções.
  • O bônus de R$ 50 vale numa mesa de rodízio, de segunda a quinta, exceto feriados. O bônus é para a próxima visita: libera depois que o vale for usado, a partir do dia seguinte. O bônus é usado de uma vez só: se a conta der menos, a diferença não fica guardada.
  • Só para consumo dentro das unidades. Não vale para delivery nem retirada.
  • Se a conta der menos que o vale, o saldo fica guardado para a próxima visita. O vale não dá troco.
  • Guarde este link: o saldo atualiza sozinho a cada uso.
